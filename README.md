## Features

- **Chat** — conversational AI with a fixed identity (Luba AI, made by Kobi / Kobiverse)
- **Accounts** — login / sign up, verified badge, admin role, owner tools
- **HTML mode** — build runnable single-file HTML apps and games inside the chat (open / copy / download)
- **Media** — photos, videos, files
- **Saved chats** — up to 100 named saves per account
- **Slash commands** — e.g. search, copy, exactly, and more
- **Web search** — optional real-time search integration
- **Leaderboard, settings, light/dark theme**
- **Luba's story** — origin story in Settings (how the project started)

**Backend:** Cloudflare Workers + KV storage.

## Origin

Luba began as a small personal project after a Roblox account ban, then grew into a full chat product with accounts, media, modes, and HTML building. Full story: in-app **Settings → Luba's story**.
