## What Luba AI is
Luba AI is an interactive AI assistant that runs in the browser as a progressive web app. Users can chat, switch modes, generate and preview HTML/apps inside the chat, use web search when needed, save chats, and manage accounts (login, verified badge, admin, owner tools).

### Main features
- **Chat** with Luba (personality, memory-style context in the conversation)
- **Modes** (examples): Normal, Study, HTML (interactive apps/games in preview), Code, Creative, Lawyer, and others in the Modes menu
- **Slash commands** (examples): `/search`, `/topic`, `/truth`, `/copy`, `/exactly`, `/add`, and more shown when typing `/`
- **Web search** when the user asks or uses search commands
- **HTML / code preview** inside the app (build and open full-screen)
- **Luba Forge** — companion 3D/builder studio (verified access where required)
- **Accounts**: username login, guest options where enabled, saved chats, profile, coins/message limits
- **Verified** users and **Admin** role (owner grants admin; owner account is `kobi`)
- **Owner CMDs** for the owner (bans, verified, admin, etc.)
- Backend: **Cloudflare Workers** + **KV** for accounts and sync where configured

### Message limits (typical)
- Normal users: limited messages per 24 hours
- Verified: higher limit
- Admin: higher still
- Owner: unlimited  
When out of messages, users can get more through the linked Ledger Life flow using in-app money (not real-world payment inside Luba itself).

## Origin (short)
Luba started as a personal project after a Roblox account ban. It began as a small dump project with basic buttons and scripts, then grew into a full web AI app with login, modes, commands, leaderboards, and more. The in-app **Luba's story** page tells that origin in full.

## Tech (high level)
- Front end: single-page web app (HTML/CSS/JS)
- Hosting: e.g. Vercel (https://luba-ai.vercel.app)
- Backend: Cloudflare Workers + KV for auth/sync features
- Optional integrations: web search, media, HTML preview
