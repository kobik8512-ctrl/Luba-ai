# Luba AI

Custom web-based AI chat assistant built by **Kobi**.

**Live:** [https://luba-ai.vercel.app](https://luba-ai.vercel.app)

## Features
- Chat with Luba (accounts, login / sign up, verified & owner roles)
- Modes including HTML mode — builds runnable single-file apps/games in chat
- Photos, files, saved chats (up to 100), slash commands
- Optional live web search
- Leaderboard, settings, theme
- Backend on Cloudflare Workers + KV
- **Luba's story** — origin story in the app (Settings)

## Origin
Luba started as a small personal project after a Roblox account ban, then grew into a full chat product with accounts, media, and HTML building.
