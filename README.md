# Luba AI

Luba AI is a custom, web-based AI chat assistant application built by Kobi.

## Features
- **Live Web Search:** Integrated web search capabilities to retrieve real-time facts, news, and weather.
- **Dynamic 2D Canvas & Code Rendering:** Executes HTML/JS canvas scripts and game logic directly.
- **Backend Infrastructure:** Powered by Cloudflare Workers and KV database storage.

## Live Application
Access the app live at: [https://luba-ai.vercel.app](https://luba-ai.vercel.app)
